# OpFlow Awareness Website

This website is a static HTML, CSS and JavaScript site. No Python or package installation is required.

## Open the website

Double-click `index.html`, or open it in a browser.

The page and all its images use local files in this folder.

## Files

- `index.html` - website structure and content
- `static/style.css` - existing website design
- `static/app.js` - demo form validation and confirmation
- `static/assets/` - images and logo

## Demo request form

The demo form sends enquiries through Formspree. It validates the name and email before submission and shows success or error feedback.
